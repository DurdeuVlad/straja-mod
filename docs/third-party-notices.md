# Third-party notices

Straja does not currently redistribute, vendor, or copy source code, textures,
animations, renderers, or other assets from Incapacitated, Piggyback, or
Vampirism. These mods are detected by loader ID only and remain optional
external installations.

The compatibility boundary therefore does not add a third-party notice to the
Straja artifact. If material is ever reused, the exact source and asset
licenses must be reviewed first and the required notice must be added here
before the change is merged.

Reference projects:

- Incapacitated — MIT License.
- Piggyback — Attribution-NonCommercial-ShareAlike 4.0 International.
- Vampirism — compatibility target to be verified per exact build; no material
  is reused by Straja.
