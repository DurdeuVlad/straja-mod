# Third-party notices

Straja does not redistribute, vendor, or copy source code, textures, animations,
renderers, or other assets from Incapacitated, Piggyback, or Vampirism. The
Vampirism compatibility adapter compiles only against the API classifier
`de.teamlapen.vampirism:Vampirism:1.21-1.10.13:api`; the full mod remains an
optional external installation and is loaded only when its loader ID is present.

The compatibility boundary therefore does not add a third-party notice to the
Straja artifact. If material is ever reused, the exact source and asset
licenses must be reviewed first and the required notice must be added here
before the change is merged.
