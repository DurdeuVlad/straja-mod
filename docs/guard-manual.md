# Manualul Străjii

Acesta este textul de referință pentru manualul Minecraft straja:training_manual. Sursa livrată în joc este [guard_manual_ro.json](../src/main/resources/data/straja/manual/guard_manual_ro.json); documentul de față îl oglindește pentru revizuire și traducere.

## Principii

Straja apără oamenii, procedura și dovezile. Serverul este autoritatea: chatul, etichetele, obiectele și BOLO-urile sunt interfețe, nu mandate.

## Flux operațional

1. Recepția înregistrează sesizarea; fluierul cere ajutor urgent.
2. Un singur străjer conduce incidentul, cu sprijin limitat și vizibil.
3. Indicativul S-001 este persistent și nu schimbă rangul.
4. BOLO-ul transmite informații și expiră; nu dă singur drept de arest.
5. Căutarea cere context valid de custodie, distanță server-side și slot actual.
6. Confiscarea mută stiva exactă într-un dosar de dovadă; geanta este doar referință.
7. Modul ESCORT/HARD se auditează și se curăță la eliberare.
8. Arestarea creează automat dosarul; Temnicerul finalizează predarea.
9. Reputația rămâne separată de rang și merit și are jurnal idempotent.

## Forță și reabilitare

Forța letală legală cere serviciu activ, sarcină autoritativă, țintă neimobilizată și ostilitate recentă. Uciderea unei persoane încătușate produce o sesizare disciplinară. Executarea sentinței și plata amenzii pot ridica reputația până la neutral; corecțiile Comisarului cer motiv și audit.
